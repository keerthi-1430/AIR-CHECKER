# Air Checker 🌤️

Air Checker is a web application that allows users to check air quality information and view real-time updates.

## Features
- Check air quality information
- Display real-time air quality updates
- Simple and user-friendly interface
- Responsive web design

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
This project was developed to practice frontend web development and working with real-time data.
